# Arc UI Forever

Icons, icon groups and bars for your cooldowns, auras and resources, all set up
from one panel. Built for WoW Forever. Type `/arcui` in game to open it.

- Cooldown icons, aura icons for buffs and debuffs, plus item, trinket, totem and ammo icons
- Bars for cooldowns, auras, resources, health, casts, swing timers and custom timers
- Put things in groups or place them anywhere, and anchor them to each other
- Decide when each one shows up: in or out of combat, by talent, and more
- Style a whole layout at once, or tweak each piece on its own
- Export and import a single icon, a group or a whole layout
- A live preview while you edit
